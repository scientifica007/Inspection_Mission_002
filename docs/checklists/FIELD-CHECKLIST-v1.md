# FIELD-CHECKLIST-v1 — Field Checklist with Text Notes

**Gate 2 Output** — Structured field checklist, text notes, optional future phone photo/file evidence; evidence is not mandatory.

No Data Model, no schema, no UI, no code, no Gate 3.

---

## Purpose

This is a field‑ready checklist for inspectors use on‑site. It mirrors the structure of CHECKLIST-MODEL-v1 but is optimized for manual annotation, pen‑and‑paper, or basic mobile text entry. No digital schema or backend is provided; evidence is explicitly optional and not mandatory.

---

```

  Evidence: [ ] optional — phone photo/file
```

## Notes on Use

- **Text Notes**: Free‑form field for any observation, decision, or deferred owner item (H1–H13). Use as needed.
- **Evidence**: Marker only. A phone photo or file may be attached later, but it is **not mandatory** for this gate. Do not delay checklist progress waiting for evidence.
- **Source tracing**: Every recorded fact should be traceable to one of the four approved source documents. Do not modify the source texts.
- **Owner decisions**: H1–H13 are intentionally left unresolved. Record any insights in the Text Notes field.
